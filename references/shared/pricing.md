## 视频生成（按 token 计费）

### Token 用量估算

```
正常视频 token = (输入视频时长 + 输出视频时长) × 宽 × 高 × 帧率 / 1024
Draft 视频 token = 正常视频 token × 折算系数
```

准确用量以 API 返回的 `usage` 字段为准。

## 费用估算速算

### 图像
```
总费用 = 生成张数 × 单价/张
例：Seedream 5.0 lite 生成 4 张组图 = 4 × 0.22 = ¥0.88
```

### 视频
```
token 量 = (输入时长 + 输出时长) × 宽 × 高 × 帧率 / 1024
总费用 = token 量 / 1,000,000 × 单价/百万 token

例：Seedance 2.0，720p 16:9 5s，无输入视频
token = 5 × 1280 × 720 × 24 / 1024 ≈ 108,000
费用 = 108,000 / 1,000,000 × 46 ≈ ¥4.97
```
