# Seedream 图像模型矩阵

## 模型对比

| 模型 | Model ID | 定位 | 分辨率 | 输出格式 |
|------|----------|------|--------|---------|
| Seedream 5.0 | `doubao-seedream-5-0-260128` | 最强，联网搜索 | 2K, 4K | png, jpeg |
| Seedream 5.0 lite | `doubao-seedream-5-0-lite-260128` | 同上（轻量） | 2K, 4K | png, jpeg |
| Seedream 4.5 | `doubao-seedream-4-5-251228` | 高品质 | 1K, 2K, 4K | jpeg |
| Seedream 4.0 | `doubao-seedream-4-0-250828` | 标准品质 | 2K, 3K | jpeg |
| Seedream 3.0 t2i | `doubao-seedream-3-0-t2i-250415` | 文生图 | 512–2048 | jpeg |

| 模式 | 说明 | 支持 |

### 自定义像素值

也可直接指定宽×高（如 `"2048x1024"`）：
- 宽高比范围：[1/16, 16]
- 需同时满足总像素范围和宽高比范围

### 多图输入规格

| 参数 | 值 |
|------|-----|
| 最大参考图数 | 14 张 |
| 参考图 + 生成图总数 | ≤ 15 张 |
| 支持格式 | jpeg, png, webp, bmp, tiff, gif（仅 5.0 lite/4.5/4.0）|
| 单图最大 | 10MB |
| 单图总像素上限 | 36,000,000 px |
| 输入方式 | URL 或 Base64 (`data:image/<fmt>;base64,<data>`) |
- Seedream 4.5 像素范围：[3,686,400, 16,777,216]
- Seedream 4.0 像素范围：[921,600, 16,777,216]
