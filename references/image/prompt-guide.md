# Seedream 图像提示词指南

## 基本原则

- 用**简洁连贯**的自然语言写明 **主体 + 行为 + 环境**
- 对画面美学有要求时，补充**风格、色彩、光影、构图**等元素
- 提示词建议不超过 **300 汉字** 或 **600 英文单词**
- 字数过多信息容易分散，模型可能忽略细节

## 提示词公式

```
主体描述 + 行为/状态 + 环境/背景 + 风格/美学关键词
```

**示例：**
> 充满活力的特写编辑肖像，模特眼神犀利，头戴雕塑感帽子，色彩拼接丰富，眼部焦点锐利，景深较浅，具有Vogue杂志封面的美学风格，采用中画幅拍摄，工作室灯光效果强烈。

## 各场景提示词技巧

### 文生图

描述越具体越好：人物外观、服装细节、场景元素、光线方向、构图方式。

### 图生图（编辑）

- 明确说明**保持什么不变**，**改变什么**
- > "保持模特姿势和液态服装的流动形状不变。将服装材质从银色金属改为完全透明的清水。"

### 多图融合

- 用「图1」「图2」指代参考图（按传入顺序）
- > "将图1的服装换为图2的服装"

### 组图生成

- 为每个场景单独写描述，场景间用明确分隔
- > "场景1为宇航员在空间站维修飞船...场景2为突然遇到陨石带袭击..."
- 可指定统一风格贯穿全组

### 联网搜索增强

- 提示词中包含需要实时信息的元素（天气、时事、商品等）
- > "制作一张上海未来5日的天气预报图"

## 风格关键词速查

| 维度 | 关键词示例 |
|------|-----------|
| 画风 | 写实、扁平化插画、3D渲染、水彩、素描、赛博朋克 |
| 光影 | 侧逆光、自然光、工作室灯光、霓虹灯、黄金时刻 |
| 构图 | 特写、中景、全景、鸟瞰、第一人称视角 |
| 色调 | 暖色调、冷色调、高饱和度、低饱和度、黑白 |
| 焦段 | 景深浅、大光圈、广角、长焦、中画幅 |
