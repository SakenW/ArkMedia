# 多模态输入规则

## 支持的组合

可自由组合以下模态（有限制）：

| 模态 | 数量 | role 值 |
|------|------|---------|
| 文本 | 1 条 | — |
| 图片 | 0–9 张 | `reference_image`, `first_frame`, `last_frame` |
| 视频 | 0–3 个 | `reference_video` |
| 音频 | 0–3 个 | `reference_audio` |

## 不支持的组合

- ❌ **纯文本 + 音频**（无图无视频）
- ❌ **纯音频输入**

必须至少有文本，或者文本 + 图片/视频中的一种。

## 进阶用法

### 通过提示词指定首帧/尾帧

多模态生视频可通过提示词指定参考图片作为首帧/尾帧，间接实现"首尾帧+多模态参考"效果。

> 首帧为`图片1`，...，尾帧定格为`图片2`。

### 严格首尾帧

如需严格保障首尾帧和指定图片一致，**优先使用 `first_frame` / `last_frame` role**：

```python
{"type": "image_url", "image_url": {"url": "<url>"}, "role": "first_frame"}
{"type": "image_url", "image_url": {"url": "<url>"}, "role": "last_frame"}
```

### 图片参考能力

- 角色/主体多视角参考
- 场景/构图参考
- Logo/品牌元素参考
- 分镜图参考
- 多元素组合参考

### 视频参考能力

- 动作参考
- 运镜参考
- 特效参考
- 整体风格参考

### 音频参考能力

- 音色参考：`「角色」说："「台词」，音色参考「音频 n」"`
- 音乐旋律参考
- 对话内容参考

## 素材 URL 要求

- 必须是**公网可访问**的链接
- 推荐使用火山引擎 TOS 对象存储，配置为公共读
- 虚拟人像和已授权素材使用 `asset://<asset ID>` 格式

## 素材指代规则

提示词中使用「素材类型+序号」格式：

- 「图片 n」= content 数组中第 n 个 `type="image_url"` 的项（从 1 开始）
- 「视频 n」= content 数组中第 n 个 `type="video_url"` 的项
- 「音频 n」= content 数组中第 n 个 `type="audio_url"` 的项

**不能用 Asset ID 在提示词中指代素材。**
